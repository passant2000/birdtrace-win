## 〇、背景与拍板记录

**用户实测反馈**（1.0.0-test1）：1.0 新做的 14 项功能太隐蔽，连作者自己都不知道怎么用；总纲提到的"生涯、作品集"找都找不到；UI 总体设计太薄弱。

**根因诊断**（代码核查结论）：
1. 8 页平铺导航无层次，"生涯/作品集"类档案概念无归口（侧栏只有"成就"一词沾边，main_window.py:22-33）；
2. 时间线页过载（timeline_page.py 1577 行）：顶部 7 按钮 + 筛选条 5 下拉 + 隐藏多选条 11 按钮 + 连拍封面右键菜单，半个软件的功能挤一页；
3. 二级交互无提示：批量操作全藏在"选择"模式后、组内对比唯一入口=连拍封面右键（burst_actions.py:149）、增量重识别 scope 藏在第二个对话框里；
4. 无统一页面骨架：8 页标题 7 处手写重复（map 24px 与其余 26px 不一致）。

**探查发现的真缺口**（不是隐蔽，是缺）：
- ⑮作品集只能"往里加"不能"浏览"——无按集筛选、无浏览页（全代码仅 tag_pick_dialog 与多选工具条两处入口）；
- ⑰版权"三态"只实现库级一态——照片级覆盖/清空 API `set_photo_copyright`（db.py:649）**零 UI 调用**；
- ⑥装备榜漏用机镜别名——camera_aliases.py:2 docstring 声称"分享卡/装备榜"两处消费，实际 stats_page.py:362 渲染原始 EXIF 串，仅分享卡过 `alias_of`；
- ⑧导入页文案未提 RAW/DNG（import_page.py:197，实际文件夹导入会收）。

**用户拍板**（AskUserQuestion 四项 + 后续指令）：
1. 导航=**分组侧栏**（图库/档案/整理/底部设置关于）；
2. 作品集=**独立页 + 时间线筛选下拉**；
3. 默认启动页=**做「首页」**（每日一鸟+最近导入+快速入口+新功能导览）；
4. 改到**深度重构**（含时间线拆包、main_window 拆编排）；
5. （补充指令）**观鸟生涯做独立页：按时间线显示鸟种、拍摄地点**，内容丰富化由本规格书设计；
6. 本轮工作模式：先出整体设计+计划（本文档），执行切 Flash。
