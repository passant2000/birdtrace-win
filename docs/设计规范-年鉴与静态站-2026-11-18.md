# BirdTrace 1.0：年度摄影年鉴 + 静态图库站视觉设计规范

## 0. 设计任务范围

本次只设计两个新增界面：

1. 年度摄影年鉴：软件内报告页 + A4 PDF 导出。
2. 静态图库站：纯静态 HTML/CSS 页面。

本次不改造 BirdTrace 现有桌面软件 UI。

### 产品视觉定位

现有 UI 已是简洁直观的 Apple 式设计。新界面延续这种视觉语言：简洁、留白、清晰、照片优先、文字层级明确、操作直观、不堆叠装饰、不做仪表盘式界面、不做后台管理系统风格。

核心原则：**照片是主角，界面是舞台。**

## 1. 统一视觉设计语言

风格关键词：Apple-like / Minimal / Editorial / Photography-first / Calm / Premium / Nature-inspired / Clean typography。

## 2. 字体和文字规范

### 2.1 字体建议

中文：Microsoft YaHei / 微软雅黑（系统优先），可选 Noto Sans SC / 思源黑体。
英文：Segoe UI（系统优先），可选 Inter；SF Pro 仅在合规字体来源允许时。
衬线标题（年鉴封面年份/大标题）：中文可选 Noto Serif SC，英文可选 Georgia。
必须提供 fallback，不依赖用户机器上不一定存在的字体。

### 2.2 字号层级

| 层级 | 字号 | 用途 |
|---|---:|---|
| Hero 标题 | 40–52px | 静态站首页主标题 |
| 年鉴封面年份 | 48–64pt | 年度封面 |
| 页面大标题 | 28–36px | 页面标题 |
| 区块标题 | 20–24px | 数据、鸟种档案 |
| 卡片标题 | 16–18px | 鸟种名称 |
| 正文 | 14–16px | 描述和信息 |
| 次级文字 | 12–14px | 英文副标题、说明 |
| 数据大数字 | 36–56px | 年度统计 |
| 注释 | 10–12px | 页码、版权信息 |

### 2.3 中英双语排版

中文在上英文在下；英文较小字号、颜色弱一级；中英间 3–5px；不塞同一行；英文缺失只显示中文不显示空占位。

## 3. 年度摄影年鉴设计

### 3.1 输出规格

A4 竖版 210×297mm（PDF 595.28×841.89pt）；安全边距四边 14mm；内容区约 182×269mm；12 列栅格、栅格间距 4mm；间距体系 4/8/12/16/24/32mm；底部轻量页码+BirdTrace 标识，不与照片争注意力。

### 3.2 页面结构

**封面**：年份（大字号）+年鉴标题+一张年度代表作（占 65–75%）+作品/鸟种/鸟点数+标识；标题不压鸟主体；不堆统计。

**年度数据总览**：标题+英文副标题、核心数据大数字、中部简洁柱状图（月度作品分布/鸟种发现趋势）、底部代表作品收尾；统计图不用复杂图例和多色。

**年度鸟种档案**（第 3 页起）：每鸟种=代表照片+中英文名上下排+拍摄次数+首录标记（小型克制标签，不用大面积彩色徽章）+首次记录日期/地区（有数据时）；每页 2–3 列，按数量自动分页。

**年度地图页**：地点分布+有效坐标+省份地区+地点数；地图简洁、浅色浅灰底/深色低对比底、点位统一强调色；无坐标不虚构位置；无数据给清晰空状态。

**年度时间线页**：按月/日组织的轻量垂直时间线（日期/地点/鸟种/代表照/当月作品数），不做复杂流程图。

**十八图精选页**：3×6 或 2×9 等组合；统一比例优先、允许少量大图突出；图间距统一、每张附简短鸟种名+日期；不足 18 张**不得重复填充**，给合理少量布局。

### 3.4 软件内报告页与 PDF 的关系

统一页面布局模型，以 A4 为基准；软件预览=缩放后页面，PDF 同一套排版规则；不维护两套布局。必须确保中文字体嵌入或正确处理，防缺字体乱码。

### 3.5 深浅色主题

两套主题；PDF 导出允许用户选主题。

## 4. 静态图库站设计

### 4.1 技术约束

纯静态 HTML/CSS/JS；不依赖 React/Vue 等框架；尽量不引第三方运行时；可直接部署普通静态空间；手机优先；深浅色（跟随 prefers-color-scheme）；中英双语；懒加载；首屏优先；不依赖后台服务。

### 4.3 响应式断点

| 设备 | 宽度 | 布局 |
|---|---:|---|
| 手机 | ≤480px | 单列或双列 |
| 大手机 | 481–767px | 双列 |
| 平板 | 768–1023px | 2–3 列 |
| 桌面 | 1024–1439px | 3–4 列 |
| 大屏 | ≥1440px | 4–5 列 |

CSS Grid 自适应，不固定卡片宽度。

### 4.4 首页

导航栏+Hero 代表照片+标识+一句介绍+统计条+精选鸟种/照片+最近更新或时间线入口+页脚。Hero 大图占主要视野、标题不遮鸟主体、手机允许缩小高度、渐变遮罩克制、首屏图优先加载。统计值必须来自实际数据。

### 4.5 鸟种网格页

卡片=缩略图+中英文名+拍摄次数；筛选胶囊（全部/类别/地区/年份/搜索）30–34px 高、胶囊圆角、选中态低饱和强调色；卡片统一比例；图片裁切保护鸟主体。

### 4.6 鸟种详情页

代表照+中英文名+次数+地区+时间分布（简洁月份柱状图）+相关照片网格；桌面左图右信息、手机上图下信息；无数据给空状态。

### 4.7 时间轴视图

年/月/日主线（日期/地点/鸟种/缩略图）；手机纵向时间线、桌面宽松分组；不要复杂动画。

### 4.8 地区视图

地图为主+简洁点位+点击显示区域照片+地区列表与地图切换；无 GPS 不随意分配位置；**不得泄露用户不希望公开的精确拍摄位置**——导出时允许用户控制地理信息公开程度，敏感地点模糊化。

### 4.9 毛玻璃导航

CSS backdrop-filter 克制使用（半透明+轻模糊+细边框+小阴影）；必须有不透明背景 fallback。

### 4.10 图片加载策略

首屏 Hero 优先；其余 loading="lazy"；固定宽高比占位防 CLS；优先 WebP/AVIF 保留兼容格式；生成网页缩略图不用原图；加载失败给简洁占位；布局不大幅跳动。

## 5. 组件清单

大图展示/图片卡片/鸟种名称组件/数据大数字/统计图/时间线/地图/标签胶囊/空状态/页码导航/深浅主题/中英双语——两界面共用视觉规范，组件分别用 Qt 和 HTML/CSS 实现；不为复用构造复杂组件框架。

## 6. 间距、圆角和阴影

间距体系 4/8/12/16/24/32/48/64；卡片内边距 16–20px、卡片间距 12–20px、页面边距手机 16px 桌面 32–48px、区块间距 32–56px；年鉴用 mm/PDF pt 不照搬网页像素。
圆角：小标签 999px、小卡片 10px、图片卡片 12px、大卡片 16px、Hero 16–20px；PDF 减少圆角避免网页化。
阴影只非常轻；不做悬浮堆叠；打印版不依赖阴影。

## 7. 可访问性和交互

对比度足够；不以颜色作唯一状态提示；控件有焦点状态；键盘导航；图片有意义 alt；触控区域适合手机；尊重 prefers-reduced-motion；主题切换不闪烁；动画只做必要反馈。

## 8. 数据真实性与空状态

最终实现必须接入真实数据。禁止：写死示例数、伪造 GPS、伪造日期、无照片时重复填充、缺失字段伪装真实。空状态提前设计：无照片/无鸟种/无 GPS/无时间数据/图片丢失/加载失败/所选年份无数据。

## 9. 交付要求

先设计后开发；第一阶段=概念稿+方向+色板+字体层级+栅格+断点+组件+间距圆角+主题+双语示例（**已完成**）；第二阶段=页面结构+Qt/PDF 实现建议+HTML/CSS 结构+懒加载+真实数据接入+空状态；第三阶段=实现。验收以实际生成的年鉴 PDF 和可运行静态站为准。

## 10. 最终设计决策

年鉴：Apple 年度回顾为主+杂志风封面灵感；静态站：沉浸画廊为主+卡片网格为辅；共用色板/字体层级/圆角/间距；深浅主题都支持；中文为主英文为辅；照片始终是视觉中心。**不包含桌面软件整体 UI 重设计。**

# 【评审补充】（开发智能体，2026-11-18）

以下为实施层补充，与上文冲突时以本节为准：

1. **强调色以本规范色板为准（自然绿 #527C70/#83B5A2）**：概念图部分版本画成 iOS 系统蓝 #0A84FF，仅作图表辅助色参考，不作主强调色——避免通用 iOS 感。
2. **色板落点**：年鉴=独立常量模块（如 app/core/yearbook.py），静态站=CSS 变量集中定义；**桌面主题不跟换**——#527C70 与桌面橄榄 #A8B36E 并存，家族感靠排版克制不靠同色。
3. **PDF 中文字体嵌入必须进 verify 断言**（生成 PDF 抽文本/渲染检查非豆腐块）；封面衬线可选打包 Noto Serif SC（OFL 可分发，约 +8~20MB 包体），与 ⑬ ffmpeg 打包同期决策；fallback 链 微软雅黑→思源黑体。
4. **静态站地图 v1 降级**：地区列表+计数+轻量 SVG 点位图（纯静态离线，不把 MapLibre/瓦片搬上网）；地理隐私直接接 ⑩ 已定的"鸟点隐私开关"（默认省市、稀有物种强制模糊）。
