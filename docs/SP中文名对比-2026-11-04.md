# 与 SuperPicky 中文名对比清单（2026-11-04）

对比源：SP 显示名 = 其鸟种库 BirdCountInfo.chinese_simplified（SP 界面实际显示的名字）；
我方名 = APK catalog_v2.bin 中文名 + cn_name_overrides.json 现有覆盖。
按 ebird_code 直接对齐（10827 个双方都有代码的物种）。

- 全量中文名不同：**1133**
- 中国名录（1401 种）内不同：**106**
- 浙江名录（655 种）内不同：41
- 上海名录（539 种）内不同：27

说明：**并非 SP 全对**。有 SP 贴国内标准而我们直译英文的（乌鹃/红翅绿鸠/白腹暗蓝鹟/麻雀/白骨顶），
也有我们贴国内标准而 SP 用台版/旧名的（饰胸鹬/理氏鹨/黄腹鹨），还有我们混入繁体字的（褐頭鴉雀）。
「跟 SP 统一」与「跟国内标准统一」在部分物种上是冲突的，需要逐条拍板。
