## 二、速览 digest 与可借鉴点（映射到我们的条目）

### Project Kestrel（建议权重 50%，维持）
- **Perch：把一次外出拍摄发布成可交互时间线**——与我们 ⑩静态站的"时间轴视图+外出(outing)概念"几乎同构，是 ⑩ 和年鉴时间线页的最佳参考；看它的 outing 组织/页面结构/分享粒度。
- **场景视图=特写+全画幅并排**——正是我们 ⑨culling 的"组内并排原像素对比"，参考其布局。
- **Culling Assistant 规则化**：最低质量线+每场景保留 N 张→Accept/Reject 两堆；"Kestrel moves. It never deletes."拒绝进 Kestrel Rejects 文件夹可自行处理——与我们的"隔离区可恢复"设计同哲学，可参考其规则参数化 UI（对应 ⑨ 三档模式）。
- IOC 全名录+地区收窄+四字环志码搜索；本地优先无账号（同我们）。
- 落点：⑨culling / ⑩静态站 / 年鉴时间线页。

### Vireo（建议权重 30%，ChatGPT 给 20%——上调）
- **XMP sidecar"永不锁定"哲学**=我们 sidecar 的同路产品，其字段组织与透明度设计可对照 ⑪XMP 写回与 sidecar 冲突策略（0.9 待设计项）。
- **KEEP/REVIEW/REJECT 三态 triage**+质量评分（锐度/曝光/构图/噪声分项）——⑨三态标记的成熟参照，分项质量维度可给美学评分参考（只看口径不抄实现）。
- **iNaturalist 直传观察记录**——④记录中心导出的国际版对照（我们做 birdreport.cn Excel+图片归集，它做 iNat API 直传，交互可参考）。
- 复杂搜索（AND/OR/NOT/括号跨字段）——⑤组合筛选的天花板形态，量力借鉴。
- Unresolved species alternatives（候选不确认不计入种数）——与我们"待复核不算确认"语义一致，互为印证。
- **警示**：它已长成 RAW 显影+降噪+接片的全编辑器——我们 〇节"不做"的反面实证。
- 落点：⑨三态 / ⑪XMP / sidecar 冲突 / ④记录中心 / ⑤组合筛选。
