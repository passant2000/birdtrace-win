## 二、双语开发规范（新代码硬性要求）

1. 用户可见文案一律内联 `t("中文", "English")`（app/i18n.py），写界面时一步到位，不留"回头补"。
2. 物种名一律 `sname(cn, en)`，不裸取 cn 字段。
3. 两个历史坑别再踩：**模块级常量不求值 t()**（存 `("中","En")` 元组、显示时 `t(*pair)`）；**局部变量禁用名 `t`**（遮蔽翻译函数，编译不报错）。
4. 数据内容不翻译：图鉴正文、文化故事、用户数据（鸟点名/备注）、选鸟种列表（中英双名同显便于跨语言查找）。
5. **提交前两道检查**：
   - `tools/check_i18n_static.py`（秒级静态扫，必须 CLEAN；合法中文用行尾 `# i18n:ok` 豁免——仅限数据码/日志/QSS）
   - `tools/verify_i18n.py`（运行时全页扫描32项；**新增页面/对话框要在此注册一行**，对话框数据列表用 skip_lists）
6. 设置页语言切换已生效（整窗重建机制，与主题切换共用 `_rebuild_window`）。

### 0.8.0 候选（2026-11-03 用户定，**先问再动**；源起对 BirdyBank 囤囤鸟的调研，见 PROGRESS 2026-11-03）

调研结论：BirdyBank（birdybank.top，Tauri/Win+Mac/免费/不开源）与鸟迹同赛道（本地优先鸟图工作台，检测→逐框→鸟种）；它**没有**地图/鸟点/迁徙/地区名录识别/成就/分享卡/年报/双语，我们领先；它值得借鉴的是数据可迁移性与整理流程。用户拍板取①②③+导出向导，**音视频不做**。

1. **标注随文件夹走**（对标 `.birdybank.json`）：每个被管理文件夹维护 `.birdtrace.json`（鸟种/确认码/评分/鸟点/备注，按 file_hash 键），导入时读回、标注变更时写出；冲突规则"已有编辑优先，旧记录不覆盖"。直击用户多机（5080 机 ↔ 本机）无法互通的痛点。与"引用导入不动原文件"原则兼容（只在目录里加一个隐藏 json）。
2. **移动硬盘离线韧性**：原文件离线时缩略图/标注/统计/图鉴照常浏览（已有 file_hash+缩略图缓存），横幅改为"X 张原图离线（F:）"不再是"丢失"；挂回自动恢复（现有 relink 按 hash 自动化），仅查看大图/重识别/分享卡需原图时提示。用户照片在 F:\成片 常离线=刚需。
3. **连拍分组 + 封面推荐**：按拍摄时间间隔（≤2s）+ 同鸟种 + 感知哈希相似度成组；封面=组内 TOPIQ 美学分最高；时间线/鸟种页折叠成组（角标"×N"），展开看全组；不改库结构只加 group 字段。用户 5850~5897 一组十几张同一只鸟=典型场景。
4. **导出向导**：选范围（日期区间/鸟种/鸟点/收藏）→ **三种模式**（用户 2026-11-03 补："导出本质=复制+重命名，给个只改名不导出的选项"）：
   - **复制到新地方**：目录层级（时间→鸟种 / 鸟种→时间 / 平铺）+ 文件名（原名 / 日期_鸟种_序号），实时预览目录树，不动原图；
   - **原地重命名**（只改名、不复制不移动）：⚠️ 触碰"照片永不移动"底线，必须**同步更新库里 path 字段**（按 file_hash 一一对应，缩略图/识别记录/时间线不受影响），否则库会报"文件丢失"；显式确认框"将原地重命名 N 个文件"+ 新旧文件名对照预览；先改库后改文件或两步事务化，改名失败回滚库记录；
   - 两种模式都：重名安全编号绝不覆盖；RAW+JPG 同名对（DSC05868.ARW/.jpg）**成对改名**；文件名非法字符（鸟种名含 `/`）清洗。
   - 与①标注随文件夹走兼容：`.birdtrace.json` 按 hash 键，改名不影响。
5. **分享卡·罕见度分值**：底层有连续值（地理先验 log[-4,2] 取 12 月最大，在所选地区全部有数据物种中按分位切 5 档），卡上现在只画档位名。加**百分位**口径（如"罕见 · 前 3%"），不用原始先验值；罕见度是地区相对的，卡上已标地区（中国·浙江）不致误导。
6. **分享卡·批量导出**：日期范围（默认当天）+ 可选鸟种 → 每鸟种一张"最美"→ 批量渲染落盘（日期/鸟种名.png）。"最美"=**美学分 × 置信度**综合（用户定：也考虑置信；并只取已确认或原始置信≥0.5 的记录，避免把待复核错名印进卡）；主题/署名/Life#/参数行**弹一次批量设置对话框**（用户定）。`render_card()` 已是纯函数，循环调用即可。
